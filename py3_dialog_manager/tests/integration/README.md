# Integration Test Contract

Deze map bevat expliciete integratie-/scenario-tests voor dialoogflow en state-updates.

- Doel: regressies zichtbaar maken in command routing, state-transities en continuous flow.
- Scope: API + state-machine contract (geen browser/DOM checks).
- Wijzig deze tests alleen na expliciete afstemming, omdat ze als regressie-contract dienen.
