pynaoqi SDK for macOS (x86_64)
================================

This folder contains the NAOqi Python 2.7 SDK for macOS, originally developed
by Aldebaran Robotics and later distributed by SoftBank Robotics.

The NAO robot platform and its SDK are currently owned by United Robotics Group.
  https://www.united-robotics.com/

This SDK is provided here for convenience to support the py2_nao_base_controller
component of NAO Studio. It is not modified from its original form.

Credits: Aldebaran Robotics / SoftBank Robotics / United Robotics Group
